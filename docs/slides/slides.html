Nightdesk5
Local-first, by construction

Customer email never touches a cloud model

  • Model endpoint must be localhost, or the code refuses to call it (unit-tested)
  • CRM, knowledge base, state and audit log are local files
  • $0 per model call; cloud LLM calls: 0
  • Model down or out of memory? A rule engine runs the same tools
  • Built for the Dell Pro Max GB10: 128 GB unified memory, on 24/7

$ ollama pull qwen2.5:32b
